15. COMO INCLUIR UM NOVO PROJETO NO FUTURO
----------------------------------------------------

Ao receber novo projeto, o assistente deve primeiro entender:

- qual problema existia
- quem demandou
- objetivo
- solução criada
- dados/fontes
- ferramentas
- arquitetura do processo
- papel de Leonardo
- status: teste, piloto, operação etc.
- evidências disponíveis
- screenshots
- resultados reais
- riscos de privacidade
- aprendizados
- possibilidade de demonstrar antes/depois

Depois decidir:
- posição do projeto na página
- título
- subtítulo
- narrativa
- arquitetura visual
- screenshots do slider
- stack
- como ele reforça RH + Direito + Dados + Tecnologia

Novo projeto deve seguir o mesmo sistema visual, mas NÃO precisa ser uma cópia exata dos cards anteriores.
Pode ganhar elementos próprios se isso ajudar a explicar melhor o case.

Evitar:
- inventar resultados
- exagerar impacto
- expor dados pessoais/corporativos
- deixar todos os projetos com textos gigantes
- repetir explicações já presentes em outros cases
